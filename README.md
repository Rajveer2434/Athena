# ⚡ Athena AI - Advanced Virtual Assistant

Athena AI is a modern AI-powered virtual assistant built using Streamlit and Groq LLMs. It combines intelligent conversation, task management, note-taking, weather updates, chat history, and voice-enabled interactions in a single dashboard.

---

## 🚀 Features

### 🤖 AI Chat

* Powered by Groq LLM
* Fast AI responses
* Natural language conversations

### 🎤 Voice Input

* Microphone support
* Record voice directly from the interface

### 🔊 Voice Output

* Listen to AI responses
* Browser-based speech synthesis
* Stop speech anytime

### 🕒 Chat History

* Stores previous conversations
* SQLite database integration
* Review past interactions

### 📋 Task Manager

* Add tasks
* Track progress
* Manage daily activities

### 📝 Notes Manager

* Save important notes
* Quick note-taking functionality

### 🌤 Weather Dashboard

* Real-time weather information
* Search weather by city

### 📊 Dashboard

* Task statistics
* Notes overview
* Productivity tracking

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Rajveer2434/Athena.git
cd Athena
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

### Run Application

```bash
streamlit run app.py
```
